# الأخطبوط | Octopus

مشروع Android شخصي بالعربية وRTL، بتصميم **أبيض وبترولي** معتمد على جميع الصفحات. الهدف النهائي: اختيار طلب واحد داخل الأخطبوط، ومقارنة تكلفته الفعلية في كيتا وهنقرستيشن، ثم تسليم السلة المختارة للمراجعة والدفع بواسطة المستخدم.

## الإصدار 0.2.0

ينتج المشروع تطبيقين منفصلين يمكن تثبيتهما معًا:

| التطبيق | الغرض | هل يقرأ تطبيقات التوصيل؟ | بيانات الأسعار |
|---|---|---|---|
| **الأخطبوط — عرض** | تجربة رحلة الطلب والتصميم على Android | لا؛ خدمة الإتاحة معطلة | أمثلة توضيحية محلية |
| **الأخطبوط** | اختبار إمكانية قراءة مؤشرات سعر حقيقية | أثناء جلسة صريحة ومحدودة فقط | مبالغ مرشحة تُقرأ من الواجهة، إن توفرت |

بيانات العرض وكوده موجودة تحت `app/src/demo` فقط، ولا تُضمَّن في APK التشخيصي. الحزمة التشخيصية `app.octopus.local`، وحزمة العرض `app.octopus.local.demo`. لا تدخل نتائج العرض سجل القراءة الفعلية.

## رحلة الطلب في نسخة العرض

اختيار مطعم ← قائمة أصناف ← أحجام وخيارات إلزامية وإضافات وكميات ← مراجعة سلة متعددة الأصناف ← اختيار عنوان ومنصات المثال ← محاكاة المقارنة ← تفاصيل التكلفة والخصم والمحفظة ← اختيار منصة ← مراجعة السلة ← معاينة التسليم.

تدعم تعديل الأصناف وحذفها، ومنع إضافة وجبة ناقصة الخيارات، والموافقة قبل تبديل مطعم السلة، وإلغاء النتائج عند تغير الطلب أو العنوان، وإيقاف المحاكاة. تبقى تكلفة الطلب منفصلة عن رصيد المحفظة والمتبقي للدفع. لا تفتح نسخة العرض تطبيقات التوصيل أو تنشئ طلبات أو تنفذ دفعًا.

## ما يعمل في النسخة التشخيصية

- الإفصاح، وإعداد الخدمة، واختيار التطبيقات المسموح بها.
- فحص تثبيت كيتا وهنقرستيشن وإصدارهما على الهاتف نفسه.
- جلسة قراءة لمنصة واحدة مدتها القصوى 90 ثانية، مع زر إيقاف ظاهر.
- قراءة مؤشرات أسعار منظمة من النافذة النشطة، دون نقر أو تمرير أو إدخال نص أو إيماءات.
- رفض القراءات المتضاربة أو غير المستقرة، وعدم تحويل المجهول إلى صفر.
- تخزين محلي لآخر 100 نتيجة مع أسباب التوقف، وتصدير مختصر بعد موافقة المستخدم.
- توقف عند قفل الجهاز أو مغادرة التطبيق أو تغير التخطيط أو ظهور مؤشرات شاشة حساسة.

المحولان تشخيصيان بمسميات عامة، ولم يُتحقق من عملهما على Honor Magic V5. قراءة مرشح لا تثبت تطابق السلة والعنوان والفرع أو أن المبلغ يشمل جميع الرسوم. الأتمتة الحقيقية لبناء السلال والمقارنة والتسليم **لم تُنفذ بعد** وتحتاج فحص واجهات فعلية أولًا.

## البناء والاختبارات

JDK 17، Android SDK Platform 35، Build Tools 35.0.0؛ الحد الأدنى Android 9 / API 28. لا يُفترض إصدار Android على Honor؛ يظهر الإصدار الفعلي داخل الإعدادات التشخيصية.

الإصدارات محددة: AGP 8.9.2، Gradle 8.11.1، Kotlin وCompose Compiler 2.1.20، Compose BOM 2025.04.01، KSP 2.1.20-1.0.32، Room 2.7.1، DataStore 1.1.4.

افتح المشروع في Android Studio، أو اضبط مسار SDK في `local.properties` محليًا، ثم:

```powershell
.\gradlew.bat :app:assembleDiagnosticDebug :app:assembleDemoDebug :app:testDiagnosticDebugUnitTest :app:testDemoDebugUnitTest :app:lintDiagnosticDebug :app:lintDemoDebug
```

المخرجات:

- `app/build/outputs/apk/diagnostic/debug/app-diagnostic-debug.apk`
- `app/build/outputs/apk/demo/debug/app-demo-debug.apk`

لتجميع اختبارات الواجهات دون تشغيلها:

```powershell
.\gradlew.bat :app:assembleDiagnosticDebugAndroidTest :app:assembleDemoDebugAndroidTest
```

تشغيل اختبارات الواجهة يتطلب جهازًا أو محاكيًا. مصدرها تحت `src/androidTestDiagnostic` و`src/androidTestDemo`. تجميعها ليس نجاحًا لاختبار الهاتف. فحوص GitHub Actions يدوية التشغيل فقط، ولا تنشر التطبيق أو تفعّل تحديثًا.

## الخصوصية

لا صلاحية إنترنت ولا Backend ولا التقاط شاشة ولا OCR. يتجاهل قارئ التشخيص الحقول القابلة للتحرير، ولا يحتفظ بالنص الخام أو شجرة الواجهة أو أسماء المستخدمين أو العناوين. التصدير يحتوي نتائج مختصرة وإصدارات التطبيقات وطراز الجهاز وإصدار Android بعد الموافقة. النسخ الاحتياطي ونقل البيانات مستبعدان. مفاتيح التوقيع وبيانات البناء المحلية لا تدخل المستودع.
