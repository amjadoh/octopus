# تشغيل تيرا خارج الكمبيوتر

الحالة: ملفات النشر جاهزة للمراجعة، لكن لم تُنشأ استضافة ولم يُنفّذ هذا النشر.

## ما يحتاجه صاحب الحساب

1. افتح https://console.cloud.google.com/ وسجّل الدخول بحسابك.
2. فعّل حساب Google Cloud والفوترة، ثم أنشئ مشروعًا باسم `Octopus AI`.
3. أعطِ المطوّر **Project ID** فقط؛ لا ترسل بطاقة الدفع أو أي مفتاح في المحادثة.

رصيد OpenAI منفصل عن فوترة Google Cloud. الحصة المجانية مشروطة بالاستخدام؛ ليست ضمانًا بعدم وجود رسوم. إعداد الحد الأدنى صفر يقلل التشغيل أثناء الخمول. الحد الأقصى نسخة واحدة وحد الطلبات داخل الخدمة لا يشكلان سقفًا ماليًا مضمونًا؛ العداد الحالي يعاد عند إعادة تشغيل الخدمة.

## تجهيز الخدمة بعد تفعيل الحساب

- فعّل Cloud Run وCloud Build وArtifact Registry وSecret Manager.
- أنشئ حساب خدمة مخصصًا للخدمة. امنحه قراءة السرّين المحددين فقط، وليس صلاحية قراءة جميع أسرار المشروع.
- خزّن مفتاح OpenAI في `octopus-openai-key`، ورمز جهاز عشوائي مستقل في `octopus-device-token` باستخدام إدخال سري أو النقل من ملف الحفظ المحلي الآمن؛ لا توضع قيمهما في المستودع أو وسيطات الأوامر أو APK.
- راجع صلاحيات حساب بناء المصدر قبل تشغيل السكربت. حدّد منطقة متاحة ومعتمدة لحسابك؛ لا تفترض أنها مقر عنوان توصيل الطعام.
- شغّل `deploy-cloud-run.ps1` بمعرّف المشروع والمنطقة وحساب الخدمة ورقمي نسختَي السرّين. السكربت لا يُفعّل الخدمات ولا ينشئ صلاحيات واسعة تلقائيًا.
- ملف `.gcloudignore` يسمح برفع ملف التنفيذ وDockerfile فقط. مسار HTTP عام لأن Android يستعمل رمز جهاز مستقل؛ `/v1/recover` يرفض الطلب دون الرمز الصحيح. `/health` يعرض جاهزية المفتاح فقط.

## قبل تفعيل المساعد في النسخة المنشورة

- أضف موافقة المستخدم وإيقاف المشاركة من داخل التطبيق، وتوفير رمز الجهاز بصورة مستقلة. الوضع الحالي مخصص لجهاز اختبار واحد؛ لا توزّع رمزًا مشتركًا داخل APK.
- اختبر الاتصال الموثق مع HTTPS من الجوال بعد إزالة تحويل USB، ثم رفض الرمز الخاطئ وانقطاع الشبكة وتغير الشاشة أثناء الانتظار.
- اختبر عرضًا فعليًا يعترض المطعم؛ تجربة تيرا الحالية نجحت على نص إعلان مسجّل دون تنفيذ نقرة. المساعد الحالي يقيّم إغلاق إعلان معروف فقط، ولا ينفّذ إضافة صنف أو دفع أو يتعامل مع أي شاشة عشوائية.
- نجاح `/health` أو البناء لا يثبت نجاح الربط أو المقارنة؛ لا تُعلن اكتمال التفعيل قبلهما.
