# تحديث الأخطبوط 1.3.15

الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله. سجّل GitHub داخل الأخطبوط عند الحاجة، ثم وافق على مُثبّت Android. البناء 22 والتوقيع السابق نفسه؛ لا تحذف النسخة الحالية أو بياناتها.

1. افتح كيتا وهنقرستيشن وتأكد من عنوان التوصيل. اخترنا في الاختبار نفس العنوان والفرع المتاح لكل منصة.
2. اختر المطعم والوجبات داخل الأخطبوط، ثم افتح صفحة المقارنة. السيناريو المختبر هو البيك: بيج بيك ×2 وبرجر فيليه دجاج حرّاق ×2 دون إضافات مختارة.
3. إذا أفرغت سلة منصة سبق استخدامها: افتح «إدارة السلال وحذفها»، ثم «أفرغت سلة … وأريد البدء من جديد»، وأكد حذف جميع أصناف هذا المطعم. لا تستخدم التأكيد قبل التفريغ الفعلي؛ فهو لا يحذف سلة المنصة نيابة عنك.
4. ابدأ المقارنة واترك الشاشة مفتوحة حتى اكتمال قراءة الإجماليين. قد يستغرق التجهيز الأول عدة دقائق. إذا كانت السلال تحتوي بالفعل الأصناف المطلوبة، راجع الكميات قبل الموافقة على استخدامها.
5. راجع النتائج؛ إذا ظهرت «قراءة سابقة — يلزم تحديثها»، افتح وأعد فحص سلة المنصة. لا تعتبر القراءة القديمة سعرًا حاليًا أو اعتمادًا للأرخص.

التطبيق يعرض الإجمالي المقروء ويتيح الانتقال للسلة؛ لا يؤكد طلبًا أو دفعًا. جميع المطاعم والإضافات ليست مشمولة بالاختبار. تيرا السحابي غير مفعّل بعد، ولا يحتاج التشغيل الأساسي إلى توصيل الجوال بالكمبيوتر. التفاصيل في ملاحظات الإصدار.
