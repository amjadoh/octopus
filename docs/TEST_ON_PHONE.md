# تحديث الأخطبوط 1.3.11

الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله. سجّل GitHub داخل الأخطبوط عند الحاجة، ثم وافق على مُثبّت Android. البناء19 والتوقيع السابق نفسه؛ لا تحذف النسخة الحالية أو بياناتها.

اختر مطعمك ووجباتك من القوائم داخل الأخطبوط. القراءة اليدوية تحفظ ما أمكن قراءته وتوضح عدد الوجبات؛ قوائم الموقع والقوائم اليدوية مستقلة. لتحديد المنطقة استخدم «موقعي الحالي» أو اختر مدينة وحيًا من الاقتراحات.

من صفحة المقارنة افتح «إدارة السلال وحذفها». زر حذف سلة الأخطبوط يحذف الطلب المحلي ونتائجه بعد التأكيد. زرا كيتا وهنقرستيشن يفتحان التطبيق المختار لتفرغ سلته بنفسك؛ لا ينفذان حذفًا آليًا. قد تتوقف إعادة التجهيز إذا لم يُثبت فراغ سلة سبق وجودها؛ لا تُعتبر رسالة التوقف دليلًا على حذفها.

هذه نسخة الإصلاحات الحالية بتصنيف إصدار عادي بطلبك، ودعم المقارنة الشاملة لجميع المطاعم والخيارات لم يكتمل. تفاصيل التحقق والقيود في PREVIEW_RELEASE.md. تنزيل التحديث لا يتطلب توصيل الهاتف بالكمبيوتر. لا تؤكد طلبًا أو دفعًا لاختبار البرنامج.
