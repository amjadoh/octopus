# تحديث الأخطبوط

من النسخة الحالية: الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله. سجّل دخول GitHub داخل شاشة الأخطبوط عند الحاجة، ثم وافق على تأكيد التثبيت الذي يعرضه Android. لا تحذف بيانات التطبيق. الإصدار 1.3.8، البناء16، والتوقيع المستقر السابق نفسه.

لم يُطلب من المستخدم إعادة الاختبارات السابقة. آخر إجمالي جهاز مؤكد هو كيتا30.63 ريال لثلاث فطائر فيتا بلا إضافات وقت القراءة؛ لا يُضمن استمراره. إجمالي هنقرستيشن والسلتان المتكافئتان لم يُتحقق منهما معًا بعد. لا تؤكد طلبًا أو دفعًا لأغراض الاختبار.
