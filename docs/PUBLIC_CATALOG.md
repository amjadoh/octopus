# المطاعم داخل الأخطبوط

تنفيذ 2026-10-25، محلي وغير منشور.

- زر الصفحة الرئيسية: «تحديث قائمة المطاعم»؛ لا يفتح المتصفح أو تطبيق توصيل.
- يحدد المستخدم المدينة والحي مرة واحدة. لا يوجد حي افتراضي أو ادعاء باستنتاج عنوانه من GPS.
- يطلب التطبيق صفحة المنطقة العامة من هنقرستيشن عبر HTTPS، ويقرأ البيانات المنظمة الموجودة فعليًا في HTML. لا يشغّل JavaScript ولا يستخدم واجهة API داخلية أو بيانات تسجيل الدخول.
- تظهر آخر قائمة محفوظة أولًا، مع وقت قراءتها. يتم التحديث عند الفتح إن تجاوزت القراءة 15 دقيقة، وزر التحديث يطلب قراءة جديدة مباشرة.
- مهمة Android دورية كل 30 دقيقة بحسب سماح النظام والشبكة؛ الموعد ليس ضمانًا لتنفيذ دقيق. لا تبدأ مقارنة أو تحرك تطبيقات التوصيل.
- أول صفحة فقط تُجلب تلقائيًا. «تحميل مطاعم إضافية» يجلب الصفحة التالية عند الطلب، بحد عرض 500 مطعم. البحث في الصفحات المحملة، وليس كتالوج السعودية كله.
- تُجلب قائمة المطعم عند اختياره، وتظهر وجباته وأسعار قائمته داخل التطبيق. إضافة وجبة تُحفظ كطلب محلي وكمية، دون تغيير سلال التطبيقات.
- بيانات الموقع لا تثبت خيارات الوجبة الإلزامية أو عنوان التوصيل أو أهلية عروض الحساب. تُقرأ هذه البيانات من التطبيقات أثناء المقارنة؛ لا يتم تحويل سعر القائمة إلى إجمالي نهائي.
- معرّفات الموقع تحمل بادئة `public-hs:`؛ لا تُستخدم كمحددات إتاحة، ولا تُعامل كقراءة خيارات كاملة.
- الأسماء المتكررة لفروع مختلفة لا تُدمج في مطعم واحد. النسخة الحالية تستبعدها من عرض الاختيار الذي يستخدم مطابقة الاسم، حتى يدعم ربط الفروع هوية أوضح.
- يُرفض تغيير النطاق، أو صفحة الحجب/الدخول، أو تغير البنية، أو اختلاف المنطقة/الفرع. تبقى آخر بيانات صحيحة ووقتها عند الفشل؛ لا تُملأ بأسعار مصطنعة.
- قاعدة `octopus_public_catalog.db` مستقلة عن الطلبات والتشخيص. تحفظ 30 صفحة عامة كحد أقصى، بحجم أقصى 3 MiB للصفحة. لا تحتوي جلسات حساب أو كلمات مرور أو صور شاشة.
- إزالة البيانات توقف التحديث وتفرغ الحفظ العام. لا تمس سلال هنقرستيشن أو كيتا.

## المقارنة

الاختيار والتحديث منفصلان عن `CatalogNavigator`. يبدأ التحكم في التطبيقات فقط من زر «قارن الإجمالي وجهّز السلتين»، أو إعادة التحقق الصريحة من سلة أُعدّت. تظل حدود دعم المسار الحالي ظاهرة: صنف واحد دون خيارات أو ملاحظات. وجود قائمة عامة لا يثبت نجاح تجهيز سلتين وقراءة إجماليين من الحسابين.

## التحقق

عينات `app/src/test/resources/public-catalog` صفحات عامة فعلية قُرئت بتاريخ 2026-10-25 لمنطقة اختبار الرياض/النرجس؛ ليست عنوان المستخدم، ولا نتائج مقارنة حالية. لا تُضمّن في APK التطبيق.

اختبارات `PublicCatalogTest` تغطي المخطط الحقيقي، المبالغ، الروابط، المنطقة والفرع، الاحتفاظ بآخر قراءة عند الفشل، عدم إعادة فتح قائمة بعد مغادرتها، وعدم تغيير اختيار الوجبات عند تحديث المطاعم.

اختبار المحاكي الحي اختياري، بواسطة معامل instrumentation `publicCatalogLive=true` مع `PublicCatalogUiTest`. يجلب بيانات عامة ويختار وجبة ويحفظها محليًا؛ لا يؤكد طلبًا ولا يدفع ولا يثبت نجاح مقارنة الحسابين. اختبار الجدولة المحلي في الفئة نفسها لا يحتاج الموقع.
