# الأخطبوط 1.3.12 — تحسين الموقع والمقارنة والواجهة

- واجهة أبيض وبترولي، بطاقات مطاعم أوضح، وتحسين مساحة عرض القائمة والبحث العربي.
- تسريع استجابة تحديد الموقع عند تعذر الحصول عليه، وتصحيح عرض المنطقة المختارة.
- إلغاء نتائج المقارنة القديمة عند تغيير المنطقة، مع الاحتفاظ بطلبك.
- التحقق من متطلبات التطبيقين قبل فتحهما، وإظهار مرحلة قراءة أسعار الوجبات قبل تجهيز السلال.
- تشديد مطابقة الأصناف والكميات ومجموع السلة قبل تعديلها، وحماية النتائج عند تغير الطلب أو المنطقة.

للتحديث: الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله، ثم الموافقة على تثبيت Android. البناء 20، بنفس شهادة التوقيع؛ لا تحتاج حذف التطبيق أو بياناته. المستودع والملفات خاصة، وقد يلزم تسجيل GitHub داخل الأخطبوط.

تفاصيل التحقق والقيود موجودة في `validation-summary-ci.json` وتقارير الإصدار المرفقة بالمصدر. المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين لجميع المطاعم والخيارات. لا يؤكد التطبيق أي طلب أو دفع.
