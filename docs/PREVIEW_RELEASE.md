# الأخطبوط 1.3.11 — إصلاح القوائم والموقع وإدارة السلال

إصدار عادي على GitHub بطلب المستخدم في 26 أكتوبر 2026. المستودع وملفات التحديث يظلان خاصين. تصنيف الإصدار لا يعني اكتمال دعم كل المطاعم والخيارات.

الجديد مقارنةً بالإصدار 1.3.10:

- إصلاح فتح قوائم المطاعم والوجبات المقروءة يدويًا مع وجود مدينة وحي محفوظين، وفصلها عن قوائم الموقع حتى عند تطابق اسم المطعم. تحديث الموقع لا يستبدل القائمة اليدوية المفتوحة.
- توضيح عدد المطاعم والوجبات المحفوظة عند إنهاء القراءة اليدوية، والتمييز بين حفظ اسم المطعم وحفظ وجباته.
- زر «استخدم موقعي الحالي» بطلب صلاحية الموقع أثناء الاستخدام، واقتراحات بحث للمدينة والحي تتسامح مع أخطاء الكتابة. تُختار الأسماء المعتمدة لدى المصدر، ولا يُغيَّر عنوان التوصيل في كيتا أو هنقرستيشن تلقائيًا. لا يوجد تتبع للموقع في الخلفية أو حفظ للإحداثيات.
- توحيد تجهيز الصنف الواحد والصنفين في هنقرستيشن وكيتا 3.13.203 عبر قراءة السلة المتحققة وتعديل الفارق إلى الكميات المطلوبة. سجل محلي محفوظ قبل التعديل يمنع إعادة إضافة معلّقة بعد الانقطاع؛ اختفاء مؤشر سلة سبق التحقق منها لا يُعدّ دليلًا على فراغها.
- «إدارة السلال وحذفها» من صفحة المقارنة: حذف طلب الأخطبوط بعد التأكيد وإزالة نتائجه؛ وزر مستقل لفتح كيتا أو هنقرستيشن وحذف سلته بنفسك. الحذف الآلي داخل المنصتين غير مطبّق. فتح المنصة يُلغي جاهزية سلتها وإجماليها السابق، ولا يحذف طلب الأخطبوط.

التحديث من الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله. سجّل GitHub داخل الأخطبوط عند الحاجة، ثم وافق على التثبيت الذي يعرضه Android. البناء 19 وشهادة التوقيع السابقة نفسها؛ لا تحذف التطبيق أو بياناته.

**المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين لجميع المطاعم والخيارات.** نجحت محليًا 456 اختبار وحدة و29 اختبار واجهة على محاكي منفصل، ويُعاد التحقق في GitHub Actions قبل النشر. هذه اختبارات للبرنامج والواجهات؛ لم يُستخدم الجوال أو تُشغّل تطبيقات التوصيل للتحقق من هذا التحديث. لا توجد أسعار حية مضمّنة أو أسعار اختبار تُعرض كأنها جديدة.

قيود قائمة: تحديد الموقع الفعلي وربطه بالحي يحتاج تحققًا على الجوال؛ رفض مصدر أسماء المناطق طلب الكمبيوتر برمز 403، وقد تتعذر القوائم الجديدة حسب الاتصال والمصدر. إثبات فراغ السلة للمرة الأولى واستعادة سلة أُفرغت خارج الأخطبوط، واستبدال سلة مطعم آخر، وتكافؤ العنوان والفرع، والخيارات والملاحظات والسلال الطويلة ما زالت تحتاج استكمالًا وتحققًا. يحتفظ التطبيق بالحماية من إعادة الإضافة بدل الادعاء بأن سلة غير مقروءة حُذفت.

لا يؤكد الأخطبوط طلبًا أو دفعًا أو اشتراكًا. بيانات الدخول والعناوين والقراءات الخام ومفاتيح التوقيع غير مرفقة، وAPK المنشور لا يحتوي مستقبل أوامر أدوات الجهاز.
