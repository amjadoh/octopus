# الأخطبوط 1.2.0 — خيارات الوجبة والطلب المحفوظ (تجريبي)

**المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين.** هذه معاينة للعمل الحالي بطلب المستخدم قبل استكمال التحقق على الهاتف. لا تتضمن أسعارًا وهمية أو إجماليات نهائية من القراءات السابقة.

## الجديد

- فتح صفحة خيارات الوجبة في هنقرستيشن وقراءة الخيارات الظاهرة. الدعم القابل للاختيار محدود بنمط «المضياف العربي — دجاج مظبي» المسجل سابقًا؛ الأنماط غير المكتملة تظهر بقيد واضح.
- اختيار الحجم والأرز والكمية وحفظ الطلب محليًا داخل الأخطبوط، مع تعديل الكميات وحذف الأصناف وحماية الطلب المحفوظ عند تغيير المطعم. الحفظ المحلي لا يضيف الأصناف إلى منصة التوصيل.
- إصلاح تمرير خيارات الوجبة، والعودة عبر أزرار معروفة عندما تفتح المنصة على آخر سلة أو منتج بدل الرئيسية.
- حفظ فحص منقح تلقائيًا أثناء جلسة القراءة أو البحث لشرح التعطل دون فحص منفصل لنفس الجلسة. لا صور أو نصوص شخصية خام أو إرسال للخارج.
- إضافة منطق قراءة بنود السلتين وتنظيم المقارنة والتحقق عند العودة في الكود؛ محولات Android التي تنفذ التجهيز الكامل وتقرأ الإجماليين النهائيين لم تكتمل.

## التحقق والحدود

109 اختبارات وحدة محلية ناجحة، وصفر أخطاء Lint قبل تجهيز الإصدار. يعيد GitHub البناء والاختبارات ويشغل اختبارات التشغيل والإعدادات على محاكي API 35 قبل النشر؛ تقرير النتائج مرفق. هذه الاختبارات لا تثبت المقارنة الفعلية أو تجهيز سلتين على Honor، ولم تُنفذ اختبارات هاتف جديدة لهذه التغييرات. البحث والقوائم السابقة لها دليل جهاز منفصل في docs/DEVICE_VALIDATION_1.1.0.md.

الإصدار المدعوم للتنقل في هنقرستيشن هو 8.0.303. قد تكون القوائم جزئية. خيارات المنتجات الأخرى أو صفحة غير معروفة تتوقف بأمان. أسعار القائمة ليست إجماليات تشمل التوصيل والرسوم. لا توجد أتمتة إنشاء طلب أو دفع.

## التنزيل والتحديث

حمّل **octopus-1.2.0.apk** وثبّته فوق النسخة السابقة دون حذف التطبيق أو مسح بياناته. رقم البناء 7، والتوقيع التجريبي الثابت نفسه. يُنشر APK واحد فقط. المستودع خاص؛ قد يلزم تسجيل الدخول إلى GitHub من متصفح الجوال.
