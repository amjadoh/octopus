# الأخطبوط 1.3.2 — إصلاح توقف قراءة السلة (تجريبي)

إصلاح لتجربة حالة التوقف بعد إضافة وجبة في هنقرستيشن، بطلب المستخدم «انشر الاصلاح خليني اجرب».

## التغيير
كان قارئ المطاعم يتوقف عند وجود checkout أو payment في معرّف أي عنصر. أصبح يميز زر الانتقال المالي المعروف شكليًا داخل قائمة أو سلة هنقرستيشن المعروفة: يخفي محتواه ويعطله ولا يقرأ عناصره الفرعية ولا يضغطه. وُحّد اجتياز شجرة العناصر بين القراءة وتحديد الهدف، وأضيف تحقق من هوية العنصر والنافذة مباشرة قبل الإجراء. الشاشات المالية الأخرى وحقول البطاقة والشاشات غير المعروفة تبقى ممنوعة. أصبحت رسالة التوقف توضح الرجوع لقائمة المطعم عندما تكون الشاشة الحالية مراجعة دفع.

## ما تحقق وما لم يتحقق
نجح بناء الإصلاح الأولي محليًا و198 اختبار وحدة دون إخفاق أو تخطٍّ وبدون أخطاء lint. أضيفت بعدها اختبارات لتطابق الهدف واجتياز الشجرة. يشترط مسار النشر نجاح206 اختبارات وحدة على الأقل وفحص واجهات التطبيق على محاكي Android API35، ثم يتحقق من هوية التوقيع وغياب بيانات العرض وأدوات التطوير. نتيجة النشر الفعلية في validation-summary-ci.json.

لم يُحدّد معرّف العنصر الذي أوقف جلسة المستخدم، ولم يُكرر الاختبار حيًا على هاتفه؛ لذلك لا نضمن أن هذا التعديل يعالج كل أسباب الرسالة. اختبارات المحاكي لا تثبت المقارنة الفعلية داخل المنصتين.

**المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين.** المسار الآلي الحالي لصنف بسيط واحد دون حجم أو إضافات أو ملاحظة، وبنية شاشة مدعومة. الإجماليات النهائية بكل الرسوم وتكافؤ الفرع والعنوان لم يكتمل التحقق منها. لا توجد أسعار تجريبية في المقارنة الحقيقية، ولا تأكيد طلب أو دفع.

## التثبيت
حمّل octopus-1.3.2.apk وثبّته فوق النسخة الحالية دون حذف بياناتك. رقم البناء10 والتوقيع السابق نفسه. يوجد ملف APK واحد. المستودع خاص ويحتاج تسجيل دخول GitHub للتحميل.
