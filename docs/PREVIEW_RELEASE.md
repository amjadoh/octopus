# الأخطبوط 0.3.1 — إصلاح الإغلاق عند التشغيل

إصلاح لطريقة تحميل شعار التطبيق في Compose: يُحمّل ملف PNG مباشرة بدل مورد XML من نوع bitmap الذي لا يقبله مسار تحميل VectorDrawable. الأيقونة المختارة لم تتغير.

يستخدم الإصدار شهادة توقيع 0.3.0 نفسها ورقم إصدار أعلى. **ثبّته فوق 0.3.0 دون حذف التطبيق أو مسح بياناته.** لا تنطبق تعليمات حذف 0.2.0 القديمة على تحديث 0.3.0 إلى 0.3.1.

أصبح النشر مشروطًا بتشغيل اختبارات واجهة فعلية على محاكي Android API 35، بما يشمل فتح التطبيق والانتقال للتطبيقات وفحص الشاشة ونافذة التحديث. ملف validation-summary-ci.json يبين عدد الاختبارات ونتيجتها. نجاح المحاكي لا يثبت التوافق على Honor أو قراءة كيتا وهنقرستيشن.

APK واحد: octopus-0.3.1.apk. المستودع خاص؛ افتح الرابط بمتصفح مسجل بحساب GitHub المصرح له.

**القدرات:** فحص قراءة فقط، أيقونة بترولية على الأبيض، الإعدادات ← تحديث التطبيق لفتح الإصدارات في المتصفح، وفحص شاشة منقح بعد موافقة المستخدم وضغطه الزر العائم. **بناء السلة والمقارنة التلقائية غير منفذين بعد، وهذا ليس إصدار المنتج الكامل.**

مصدر فني: https://android.googlesource.com/platform/frameworks/support/+/HEAD/compose/ui/ui/src/androidMain/kotlin/androidx/compose/ui/res/PainterResources.android.kt
