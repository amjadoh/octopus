# الأخطبوط 1.3.13 — إصلاح حفظ الموقع وإعادة المقارنة

- إصلاح حفظ المنطقة بعد اختيار الموقع الحالي.
- تحسين التعامل مع شاشات كيتا الحالية ونافذة اقتراحات هنقرستيشن.
- التحقق من السلة الموجودة قبل تعديلها وإعادة قراءة الإجماليين عند تكرار المقارنة.
- تحسين مطابقة الحجم والإضافات والكميات في دليل السلة، ورفض الصفوف الناقصة أو المكررة.

للتحديث: الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله، ثم الموافقة على تثبيت Android. البناء 21 بنفس شهادة التوقيع، دون حذف بيانات التطبيق. الملفات خاصة وقد يلزم تسجيل GitHub داخل الأخطبوط.

نجحت رحلة فعلية لطلب كودو البسيط وإعادة المقارنة وتسليم السلتين. المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين لجميع المطاعم والخيارات؛ اختيار الإضافات تلقائيًا لم يُربط بالرحلة الكاملة بعد. لا يؤكد التطبيق طلبًا أو دفعًا.
