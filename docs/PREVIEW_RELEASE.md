# الأخطبوط 1.3.7 — تصميم مصعب والتحديث التلقائي (تجريبي)

## الجديد

هوية مصعب الأصلية بالكحلي والمرجاني والأبيض، وخط IBM Plex Sans Arabic، وترويسات رحلة الطلب وبطاقات المطاعم الجديدة. ينتظر التحديث روابط الإصدار التي تتأخر في الظهور ويختار أحدث APK تلقائيًا دون اختيار ملف.

تبدأ الرئيسية دون مطعم مختار. لا يتحول الطلب المحفوظ إلى طلب حالي عند فتح التطبيق؛ يمكن استئنافه صراحة من صفحة المقارنة. نُقل ترتيب الرئيسية من مرجع مصعب: ترويسة التوصيل والعنوان، البحث، شريط التطبيقات، ثم المطاعم، مع عرض المعلومات المقروءة فقط بدل أسماء أو أسعار أو حالات اتصال تجريبية.

شريط طلب ثابت أسفل قائمة المطعم مع زر مراجعة الطلب والمقارنة، والبحث في الوجبات المقروءة وإظهار الكمية المختارة. تُلغى الأسعار وحالات السلال السابقة عند تعديل الطلب أو حذفه، وتبقى نتيجة المنصة المتاحة عند تعذر قراءة الأخرى. تحسّن مسار إضافة كيتا للشكل المحفوظ فقط، مع إيقاف الإضافة عند الخيارات أو الشاشة غير المقروءة.

## تقدم المقارنة في هذا الإصدار

أُصلح التعرف على بطاقة نتيجة كيتا 3.13.203 بناءً على شجرة فعلية من الهاتف، وأُصلح دخول استعراض هنقرستيشن عند ظهور ثمانية أقسام. أُضيف مسار محدود لقراءة إجمالي مراجعة الطلب وعرض القراءة الصريحة مع وقتها، دون حساب قيم مجهولة أو خلط سعر الأصناف بالإجمالي النهائي. لم ينجح اختبار استخراج الإجماليين من المنصتين؛ لا يعني وجود المسار أنه مثبت على الجهاز.

في آخر اختبار توقف هنقرستيشن عند زر سلة معطل بعد إضافة قطعة واحدة قبل ضبط الكمية إلى ثلاث. تصحيح ترتيب ضبط الكمية ومسار اختيار المطعم اللاحق ما زالا يحتاجان الإكمال. لا تُزاد الكمية أو تُضاف أصناف لتجاوز الحد الأدنى بصمت. لا تعد هذه النسخة بتجهيز السلتين أو المقارنة التلقائية المكتملة.

## التحديث من داخل الأخطبوط

الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله. تظهر نافذة GitHub داخل الأخطبوط للوصول إلى الملفات الخاصة. سجّل الدخول بنفسك بالحساب المخول إن طُلب منك، فيقرأ التطبيق روابط إصدار هذا المستودع ويبدأ تنزيل النسخة الأحدث. يبقى الملف في مساحة التطبيق، ويتحقق الاسم والإصدار والتوقيع قبل فتح تأكيد تثبيت Android. لا حاجة لاختيار APK من التنزيلات. قد يطلب Android السماح للأخطبوط بتثبيت التطبيقات أول مرة.

لا يُضمّن مفتاح GitHub في APK. تُستخدم جلسة متصفح التحديث لتنزيله من GitHub فقط، ولا تُرسل إلى مخازن ملفات الإصدار عند إعادة التوجيه. يمكن تسجيل الخروج داخل شاشة التحديث. أُضيف اتصال الإنترنت لهذه الميزة، ولا يُرسل محتوى تطبيقات التوصيل إلى الشبكة.

هذه النسخة تضيف الآلية الجديدة؛ النسخ القديمة تحتاج تنزيل هذا التحديث بالطريقة السابقة مرة واحدة. لا تحذف التطبيق أو بياناته. رقم البناء 15 والتوقيع المستقر نفسه.

## التحقق والحدود

يشترط النشر نجاح بناء APK وفحص Lint واختبارات المنطق واختبارات واجهة على محاكي Android. تتضمن اختبارات التحديث رفض المصادر غير المعتمدة والإصدارات القديمة والتوقيع المختلف، وعدم إرسال جلسة GitHub إلى وجهة إعادة التوجيه، ورفض صفحات الدخول والتنزيل الناقص. اختُبر مسار التحديث الجديد على Honor Magic V5 بنسخة اختبار تحمل رقم بناء 13، ثم تحقق تثبيت الإصدار الخاص 1.3.6 برقم بناء 14 بواسطة مُثبّت Android بتاريخ 2026-10-22. سجّل المستخدم دخوله بنفسه؛ لم تُقرأ بيانات الدخول. يظل إصدار 1.3.7 خاضعًا لفحوص البناء والواجهة قبل النشر.

**المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين.** تجهيز الطلب الحالي محدود بصنف واحد بلا خيارات أو ملاحظات مع كمية متغيرة. الإجماليان النهائيان ومطابقة الفرع والعنوان وتجهيز طلب عام متعدد الأصناف لم تكتمل. الأسعار المحفوظة لا تُعرض كقراءات حية، ولا يُختلق إجمالي أو ترتيب للأرخص.
