# الأخطبوط 0.2.0 — إصدار تجريبي

نسخة للاختبار اليدوي على Android، بالأبيض والبترولي. اختر ملف APK من Assets:

- **octopus-demo-0.2.0.apk**: تجربة اختيار المطعم والوجبات والأحجام والإضافات والسلة ومحاكاة المقارنة واختيار المنصة. جميع المطاعم والأسعار توضيحية. لا يفتح تطبيق توصيل فعليًا.
- **octopus-diagnostic-0.2.0.apk**: اختبار قراءة مؤشرات إجمالي من شاشة كيتا أو هنقرستيشن، بعد الإفصاح وتفعيل خدمة الإتاحة. قراءة فقط، دون نقر أو تعديل سلة أو إنشاء طلب أو دفع.

**المقارنة الآلية الفعلية وبناء السلال والعودة لسلة مطابقة لم تُنفذ بعد. لم تُختبر النسخة على Honor Magic V5 أو محاكي.**

بُني الملفان داخل GitHub Actions بعد نجاح اختبارات الوحدات وفحص Android Lint، والتحقق من توقيع APK وعزل بيانات العرض. الاختبارات على الهاتف لم تُنفذ. أُرفق تقرير CI وبصمات الملفات وتعليمات التجربة والمصدر.

الحد الأدنى Android 9 / API 28. يمكن تثبيت النسختين معًا؛ لا تحتاج نسخة العرض خدمة الإتاحة. المستودع خاص، لذلك يلزم تسجيل الدخول بحساب GitHub المالك للوصول إلى التحميل من الجوال.

التوقيع **debug تجريبي** مولّد في بيئة GitHub، ويختلف عن توقيع ملفات APK المحلية السابقة. إذا كانت النسخة المحلية مثبتة، فقد يرفض Android تحديثها فوق هذا الملف بسبب اختلاف التوقيع. صدّر سجلك أولًا إن احتجته، ثم أزل النسخة التجريبية السابقة وثبّت هذه النسخة؛ إزالة التطبيق تمسح بياناته المحلية. لا تزل أي تطبيق توصيل.

هذه نسخة تجريبية غير إنتاجية، ولا توجد ضمانات بأن قراءة السعر ستنجح قبل اختبار واجهة التطبيق الفعلية.
