# الأخطبوط 1.3.4 — التحديث الخاص ومسار تجهيز السلال (تجريبي)

معاينة نشرها المستخدم ليرى التعديلات الحالية. **المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين.** لا يقدم هذا الإصدار إجماليين نهائيين متحققين أو ترتيبًا مؤكدًا للأرخص.

## التغييرات

- فصل زر مقارنة أسعار الوجبات عن مسار تجهيز السلتين بالتتابع، وإظهار نتيجة كل منصة عند الفشل أو تعذر قراءة المراجعة.
- منع الانتقال إلى منصة أخرى عند الإيقاف أو تغير الطلب، وحماية محاولات الإضافة من التكرار.
- إصلاح قراءة المبالغ ذات علامات اتجاه النص، وخيارات فطيرة مدور في هنقرستيشن، وعبارة عدم وجود إضافات في السلة.
- دعم قراءة سلة كيتا الحالية المطابقة وتعديل الكمية عبر البنية المحفوظة؛ إضافة منتج كيتا من سلة فارغة لا تزال محدودة بالإصدار المدعوم.
- قراءة أسماء الرسوم ومبالغها من عناصر المراجعة المجمعة دون تحويل البيانات الجزئية إلى إجمالي نهائي.
- الإعدادات ← تحديث التطبيق: فتح GitHub الخاص، ثم اختيار APK المنزّل وفحص اسم التطبيق والتوقيع ورقم الإصدار قبل فتح مثبت Android.

## ما لا يزال ناقصًا

المراجعة النهائية للمنصتين وربط الإجماليين الفعليين بالترتيب غير مكتملين. الأسعار المحفوظة لا تُعرض كأسعار حالية. لا تُعتبر السلة المجهزة دليلاً على إجمالي التوصيل أو تكافؤ الفرع والعنوان.

التحديث الخاص يتطلب تنزيل APK من GitHub المسجل بحسابك ثم اختيار الملف داخل الأخطبوط؛ ليس تنزيلًا مباشرًا مثل الأثيل. لم تُنشر ملفات أو بيانات على مصدر عام.

المسار الحالي محدود بصنف بسيط واحد دون حجم أو إضافات مختارة أو ملاحظة. لا يُؤكد التطبيق طلبًا أو دفعًا.

## التحقق والتثبيت

اجتاز الكود محليًا 249 اختبار وحدة والبناء. تفرض عملية النشر إعادة اختبارات الوحدة وlint واختبارات واجهة الأخطبوط على محاكي Android API35 والتحقق من التوقيع وغياب أدوات تحكم التطوير. لا تثبت اختبارات المحاكي العمل داخل تطبيقات التوصيل الفعلية. تقرير CI مرفق في validation-summary-ci.json.

حمّل octopus-1.3.4.apk وثبّته فوق النسخة الحالية دون حذفها. رقم البناء 12 والتوقيع المستقر السابق نفسه. المستودع والملفات خاصان ويتطلب التحميل حساب GitHub مخولًا.
