# الأخطبوط 1.1.0 — بحث المطاعم والقوائم (تجريبي)

**هذا تحديث جزئي تجريبي؛ المقارنة الفعلية بين كيتا وهنقرستيشن وتجهيز السلتين غير مكتملين.**

## الجديد

- شاشة «المطاعم» تبحث في هنقرستيشن من حسابك النشط، ثم تعرض النتائج الحقيقية داخل الأخطبوط.
- فتح قائمة مطعم وقراءة الأصناف وأسعار القائمة الظاهرة، دون منتجات أو أسعار تجريبية.
- موافقة مستقلة للتنقل والبحث والتمرير، وزر إيقاف ظاهر. لا يسمح هذا المسار بتعديل السلة أو الطلب أو الدفع.
- تصحيح قراءة حقل بحث Flutter، والتعرف على الاقتراحات، والانتقال من النتائج إلى القائمة.
- إضافة أساس محلي لنموذج الطلب والمطابقة والتسعير والتحقق؛ وجود هذا الأساس لا يعني اكتمال رحلة المقارنة.

## الحدود

القائمة قد تكون جزئية، وأسعارها ليست إجماليات نهائية ولا تشمل بالضرورة التوصيل والرسوم. لا يثبت تشابه الاسم تطابق الفرع أو العنوان. لا توجد إضافة وجبات إلى سلتَي كيتا وهنقرستيشن أو مقارنة تلقائية مكتملة في هذا الإصدار. لا يُنفذ شراء أو دفع.

اختُبر البحث وفتح قائمة على Honor يعمل بـ Android 16. اختبارات الواجهة الآلية في GitHub تتحقق من التشغيل والإعدادات؛ لا تتحقق من تطبيقات التوصيل. راجع docs/DEVICE_VALIDATION_1.1.0.md لتفاصيل الدليل وحدوده.

## التثبيت

حمّل octopus-1.1.0.apk وثبّته فوق 1.0.0 دون حذف التطبيق أو مسح بياناته. يحمل رقم بناء أعلى وشهادة التوقيع السابقة نفسها. المستودع خاص، لذلك قد يلزم فتح GitHub في متصفح مسجل بحسابك.

مسار التحديث داخل الأخطبوط: الإعدادات ← تحديث التطبيق ← فتح صفحة التحديث. التنزيل والتثبيت يتطلبان موافقة Android؛ لا يوجد تثبيت صامت.

الإصدار المدعوم للتنقل في هذا التحديث: هنقرستيشن 8.0.303. نجح البحث وفتح قائمة مطعم يبيع الفول على Honor. يظل اكتمال القائمة والتوفر وتجهيز السلة والمقارنة غير متحققين.
