# الأخطبوط 1.3.10 — آخر إصلاحات المقارنة والتحديث (تجريبي)

تحديث تجريبي للتحسينات الحالية، نُشر بطلب المستخدم في 26 أكتوبر 2026 لتجربته. مستودع التطبيق وملفات الإصدار يظلان خاصين.

الجديد مقارنةً بالإصدار 1.3.9:

- تحسين تصنيف بعض شاشات الملاحظات غير المدعومة في كيتا، لإظهار سبب ثابت بدل انتظار انتهاء مهلة قراءة الصنف. هذا لا يفعّل قراءة سعر أو إضافة صنف من تخطيط لم يُتحقق منه.
- تصحيح اختيار أحدث تحديث عند اجتماع رابط APK قديم مع قسم ملفات إصدار أحدث لم يُحمّل بعد. المقارنة رقمية، لذلك يأتي 1.3.10 بعد 1.3.9، ويبدأ تنزيل الملف المعتمد دون اختياره يدويًا.
- منع اعتبار السلة مجهولة المطعم مطابقة، والتحقق من الفرع قبل طلب موافقة غير قابلة للتنفيذ في منطق المطابقة العام. هذا إصلاح تمهيدي؛ لا يضيف مسار استبدال سلال مطاعم مختلفة داخل محولات Android.

ويشمل كذلك التحسينات الموجودة في 1.3.9:

- تحسين البحث عن الصنف داخل مطعم هنقرستيشن، وقراءة خياراته والعودة للقائمة بدل الاعتماد على التمرير الطويل. فتح نتيجة فريدة فقط، دون الضغط على إضافة من نتائج البحث.
- تجهيز طلب من صنفين بسيطين دون إضافات، والتحقق من جميع صفوف السلة وكمياتها بعد كل إجراء. نجح على الجهاز مسار هنقرستيشن من قائمة رُصدت فارغة حتى سلة كودو: ناتشوز ×٢ وبطاطس وسط ×٣، ثم قراءة إجمالي المراجعة؛ لا تأكيد طلب أو دفع.
- تحسين تمرير قائمة كيتا عند رفض أمر التمرير المنظم، ضمن حدود القائمة المتحققة وفوق شريط السلة. يتوقف عند إغلاق المطعم أو ظهور خيارات أو شاشات غير مدعومة.
- انتهاء مهلة قراءة منصة واحدة يترك سعرها غير متاح ويسمح بمحاولة قراءة المنصة الأخرى، دون اختلاق أسعار أو احتساب طلب جزئي. زر الإيقاف وتغير الطلب والشاشات الحساسة يوقفون العملية كاملة.
- تحققت مقارنات سابقة من زر الأخطبوط لطلب كودو المحدد مع سلال موجودة، وتغييرات كمية وتسليم السلتين. هذه نتائج للحالات المسجلة، وليست إثباتًا لدعم أي مطعم أو أي خيارات.
- تحديث واحد فوق النسخة الحالية بالتوقيع المستقر ورقم البناء 18. الإعدادات ← تحديث التطبيق؛ سجّل GitHub داخل الأخطبوط عند الحاجة. ينزّل التطبيق APK ويفحصه، ثم يعرض مُثبّت Android لتأكيد التثبيت. لا تحذف التطبيق القديم أو بياناته.

**المقارنة الفعلية وتجهيز سلتَي كيتا وهنقرستيشن غير مكتملين لجميع المطاعم والخيارات.** آخر محاولة لمطعم «فطيرة» توقفت عند شاشة خيارات كيتا ذات حقل الملاحظات؛ لا يوجد إجماليان أو سلتان جاهزتان لهذا الطلب. ما زال التحقق من المسار الكامل في النسخة الجديدة بسلتين فارغتين، وتكافؤ الفرع والعنوان، واستبدال سلة مطعم آخر تلقائيًا، والخيارات والملاحظات والسلال الطويلة غير مكتمل. لا تفترض الجاهزية العامة من نجاح طلب الاختبار.

أسعار الاختبارات أرقام تاريخية في التقارير فقط؛ لا تُعرض كأسعار حية ولا تُحقن داخل التطبيق. المقارنة تحتاج حسابات المستخدم النشطة وخدمة إمكانية الوصول أثناء الاستخدام. لا تنفذ شراء أو دفعًا أو اشتراكًا.

ينشر الإصدار بعد نجاح البناء واختبارات الوحدات وLint واختبارات واجهة المحاكي في GitHub Actions. المحاكي يتحقق من واجهة الأخطبوط ولا يثبت تكامل منصات التوصيل الفعلية. APK العادي لا يتضمن مستقبل أوامر أدوات الجهاز. بيانات الدخول والعناوين والقراءات الخام ومفاتيح التوقيع غير مرفقة.
