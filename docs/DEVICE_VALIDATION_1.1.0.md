# دليل التحقق وحدوده — 1.1.0

## دليل جهاز فعلي

- الجهاز: Honor MBH-N49، Android 16 / API 36. لا تتضمن هذه الوثيقة معرّف الجهاز أو العنوان أو الحساب.
- هنقرستيشن 8.0.302: نجح محرك التطبيق نفسه في البحث وقراءة نتائج مطاعم، ثم فتح قائمة ريدان وقراءة ثلاثة أصناف حقيقية. هذا ليس جمعًا شاملًا للقائمة أو إثباتًا للمقارنة.
- كيتا 3.12.501: عُوينت عبر USB سلة موجودة تطابق طلبًا محددًا؛ لم يبنها التطبيق، ولم تثبت قراءة إجماليها النهائي.
- مبلغ 36 ريال الذي عُوين في سلة هنقرستيشن كان مجموع الأصناف؛ لا يُقدم بوصفه سعرًا نهائيًا يشمل الرسوم.
- هنقرستيشن 8.0.303: نجح البحث من محرك الأخطبوط وفتح قائمة عريكة السلطان وقراءة أصناف تشمل فول قلابة صاج وفول صنعاني وفول بالجبنة. القائمة جزئية ولم يُثبت الوصول إلى نهايتها. أضيف دعم اقتراحات البحث السابقة وتنبيه عرض القائمة، واختبارات استبعاد شارات الخصم وأعداد الطلبات من أسماء الأصناف. لم تتغير السلال.

## ما لا يثبته هذا الإصدار

لم يكتمل تنفيذ خيارات الوجبة وإضافتها من الأخطبوط إلى التطبيقين، أو التحقق الآلي من تطابق الفرع والعنوان، أو استخراج الإجماليين النهائيين، أو العودة الموثقة لسلة مختارة. لا تُدرج هذه الوظائف ضمن الميزات المكتملة.

## التحقق الآلي

مجموعة اختبارات الوحدة يعاد تشغيلها في كل نشر، وتقرير CI يسجل العدد الفعلي. أربعة اختبارات واجهة على Honor نجحت مجددًا مع نسخة 1.1.0 للشاشة الرئيسية واختيار المنصات والتشخيص والتحديث. يعيد مسار النشر اختبارات الوحدة والفحص واختبارات الواجهة على محاكي API 35، ويتحقق من شهادة التوقيع وعزل بيانات العرض.

اختبارات المحاكي والبيانات المصطنعة لا تثبت عمل منصات التوصيل. لا تُرفع أشجار الواجهة أو بيانات العنوان أو ملفات الجهاز إلى المستودع أو الإصدار.
