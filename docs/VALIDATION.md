# سجل التحقق

## 0.3.0 — إصلاح نقص دليل التشخيص

فحصنا سجلًا فعليًا من 0.2.0: انتهت محاولتا كيتا وهنقرستيشن بالمهلة دون مبلغ مرشح، ومحاولة أقدم توقفت بسبب قفل الهاتف. وصلت الخدمة إلى عناصر واجهة؛ لا تثبت أعدادها إتاحة نصوص السعر. لا يكشف سجل v1 عدد التسميات المالية أو الأرقام أو سبب عدم الربط، لذلك لا نجزم بسبب الفشل.

المصدر الجديد يضيف التقاط بنية منقحة بعد ضغط المستخدم زر الفحص، وإفصاحًا منفصلًا، وإحصاءات قراءة آمنة، وطلب معرفات العناصر. لا يوجد منفذ نقر أو تجهيز سلة. 0.3.0 ليس ادعاء إصلاح قراءة الإجمالي أو اكتمال المقارنة.

تُشغّل الاختبارات المحلية ثم فحوص CI قبل نشر APK واحد. تقرير `validation-summary-ci.json` المرفق بالإصدار يسجل النتيجة الفعلية والتوقيع وبصمات الملفات. تتضمن الاختبارات فحص تنقيح الهوية والعنوان والأرقام الحرة ومعرفات الموارد والتسميات الخطرة والتسميات المالية المدمجة، إلى جانب اختبارات الأسعار والأمان الأصلية. لا تثبت هذه الاختبارات قراءة تطبيقات التوصيل على الهاتف.

اختبارات واجهة الفحص تُجمع ولا تُشغّل دون جهاز/محاكي. لم يُختبر الزر العائم الجديد أو استقرار بنية الشاشات أو استرجاع السجل الجديد على Honor بعد. السجل الأصلي لا يُرحّل ترحيلًا مدمرًا؛ أضيفت قاعدة فحص مستقلة. يختلف التوقيع الثابت الجديد عن توقيع 0.2.0؛ الانتقال يتطلب تثبيتًا جديدًا بعد تصدير السجل القديم. مسار تحديث الإعدادات يفتح المتصفح، ولم يُختبر على Honor بعد.

## النسخة السابقة

نجحت محليًا اختبارات 0.2.0 وعددها 37 اختبارًا مختلفًا، بـ52 تنفيذًا عبر نسختين. نجحت كذلك فحوص GitHub قبل إصدار 0.2.0. هذه نتائج بناء ومنطق محلي؛ سجل الهاتف المرسل لاحقًا يثبت أن قراءة الإجمالي لم تنجح في المحاولتين المسجلتين، فلا تعتبر النسخة السابقة مثبتة الجدوى للمقارنة.
