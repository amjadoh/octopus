# تحديث التطبيق الخاص

المسار: الإعدادات ← تحديث التطبيق ← التحقق من التحديث وتنزيله.

المستودع وملفات APK خاصان. يسجل المستخدم دخوله إلى GitHub داخل شاشة الأخطبوط عند الحاجة، ولا يرسل كلمة المرور أو رمز التحقق في المحادثة. يكتشف التطبيق ملف APK من أحدث إصدار وينزله دون اختيار ملف يدوي، ويتحقق من الحزمة والتوقيع ورقم البناء ثم يفتح مُثبّت Android. موافقة المستخدم على التثبيت مطلوبة؛ لا يوجد تثبيت صامت. قد يطلب Android السماح بتثبيت التطبيقات من الأخطبوط.

الإصدار التجريبي المطلوب نشره1.3.10، البناء18، يستخدم شهادة التوقيع التجريبية المستقرة نفسها. تحقق النشر يقارن بصمتها العامة مع PREVIEW_SIGNING_CERT_SHA256.txt؛ المفتاح الخاص وكلمة مروره محفوظان خارج الكود وفي GitHub Secrets. النسخ ذات الشهادة نفسها ورقم بناء أقل يمكن تحديثها دون حذف بياناتها.

آخر بناء محلي عادي اختُبر دون مستقبل TEST_CATALOG. اختبار ترقية هذه النسخة على Honor بعد فصله لم يُنفذ؛ اختبارات التحديث السابقة لا تُنسب تلقائيًا لهذا الملف. راجع وصف الإصدار لمعرفة حدود المقارنة الفعلية.
