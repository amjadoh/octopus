# تحديث التطبيق

المسار: أيقونة الإعدادات ← تحديث التطبيق ← فتح صفحة التحديث.

تعرض الشاشة رقم الإصدار المثبت وتفتح قائمة الإصدارات في المتصفح. المستودع خاص؛ يلزم تسجيل الدخول بحساب GitHub المصرح له في المتصفح، ثم تنزيل APK وتأكيد التثبيت في Android. لا تُطلب بيانات GitHub داخل الأخطبوط، ولا يوجد فحص تلقائي أو تثبيت صامت أو تنزيل داخل التطبيق حاليًا.

من إصدار 0.3.0 تستخدم النسخ المنشورة شهادة توقيع تجريبية ثابتة. تتحقق عملية النشر من بصمتها العامة الموجودة في PREVIEW_SIGNING_CERT_SHA256.txt. لا تنشر المفتاح الخاص أو كلمة مروره ضمن المستودع أو ملفات الإصدار.

إصدار 0.2.0 السابق موقّع بمفتاح مؤقت مختلف؛ الانتقال إلى 0.3.0 يتطلب تصدير السجل ثم إزالة النسخة القديمة مرة واحدة وتثبيت الجديدة وإعادة تفعيل الخدمة. لا توجد آلية استيراد للسجل المصدّر حاليًا. احتفظ به كمرجع. تحديثات 0.3.0 التالية بالتوقيع نفسه ومع رقم إصدار أعلى يمكن تثبيتها فوق النسخة الحالية. هذا لا يثبت أن ترقية فعلية اختُبرت على Honor؛ يلزم اختبارها على الجهاز.

الإصدار الحالي تشخيصي: يختبر قراءة واجهة حقيقية، ولا ينفذ بعد تجهيز السلال أو المقارنة التلقائية.
